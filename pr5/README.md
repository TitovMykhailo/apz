## 4. Короткі теоретичні відомості

Amazon Elastic Compute Cloud, або Amazon EC2, — це хмарний сервіс, який надає користувачам віртуальні сервери. В EC2 можна вибрати операційну систему, кількість процесорів, обсяг оперативної пам’яті, тип диска та параметри мережі.

### Основні поняття Amazon EC2

**Instance** — екземпляр віртуальної машини, запущений у хмарній інфраструктурі AWS.

**AMI (Amazon Machine Image)** — шаблон, який містить операційну систему та початкове програмне забезпечення для створення віртуальної машини.

**Instance type** — набір апаратних характеристик віртуальної машини: кількість віртуальних процесорів, обсяг оперативної пам’яті та мережеві можливості.

**Key pair** — пара криптографічних ключів, яка складається з відкритого та приватного ключів. У Windows-інстансах приватний ключ використовується для розшифрування початкового пароля адміністратора.

**Security Group** — віртуальний мережевий екран, який визначає дозволений вхідний і вихідний трафік.

**EBS (Elastic Block Store)** — постійне блокове сховище, яке використовується як диск віртуальної машини.

**RDP (Remote Desktop Protocol)** — протокол віддаленого доступу до графічного робочого столу Windows.

Додано правило вхідного трафіку:

# 7. Відповіді на контрольні питання

## 1. Яка різниця між Stop та Terminate?

**Stop** зупиняє роботу віртуальної машини, але зберігає сам інстанс, його EBS-диск, налаштування та файли. Машину можна повторно запустити. Після повторного запуску звичайна публічна IPv4-адреса може змінитися.

**Terminate** остаточно видаляє інстанс. Повторно запустити його неможливо. EBS-томи з параметром `Delete on termination` також видаляються. Перед виконанням `Terminate` необхідно зберегти всі потрібні дані.

---

## 2. Чим відрізняються On-Demand, Reserved та Spot інстанси?

**On-Demand Instances** використовуються без довгострокових зобов’язань. Користувач оплачує ресурси за фактичний час роботи. Цей варіант підходить для коротких, нерегулярних і тестових навантажень.

**Reserved Instances** передбачають довгострокове зобов’язання, зазвичай на один або три роки. Вони можуть надавати знижку порівняно з On-Demand і підходять для постійних передбачуваних навантажень.

**Spot Instances** використовують вільні обчислювальні ресурси AWS зі значною знижкою. AWS може перервати роботу такого інстансу, коли ресурси знадобляться іншим користувачам. Spot підходить для задач, які допускають переривання.

---

## 3. Навіщо потрібен Security Group?

Security Group виконує функцію віртуального мережевого екрана. Він контролює вхідний і вихідний трафік EC2-інстансу.

Для Windows-інстансу Security Group повинен дозволяти вхідні RDP-з’єднання через TCP-порт 3389. З міркувань безпеки доступ рекомендується дозволяти лише з конкретної IP-адреси, а не з усього Інтернету.

---

## 4. Що таке Region в AWS?

Region — це окрема географічна область інфраструктури AWS, у якій розміщено центри обробки даних.

Вибір регіону впливає на:

* затримку мережевого з’єднання;
* вартість використання сервісів;
* доступність окремих типів ресурсів;
* законодавчі вимоги до розміщення даних;
* адресу створених хмарних ресурсів.

У цій роботі використано регіон:

```text
Europe (Frankfurt) — eu-central-1
```

---

## 5. Як підключитися до Windows-інстансу?

Для підключення необхідно:

1. Запустити Windows-інстанс.
2. Дочекатися проходження системних перевірок.
3. Переконатися, що Security Group дозволяє RDP через порт 3389 з IP-адреси користувача.
4. Отримати публічну IPv4-адресу або Public DNS.
5. Відкрити вкладку `Connect → RDP client`.
6. Завантажити приватний `.pem`-ключ.
7. Натиснути `Decrypt password`.
8. Запустити Remote Desktop Connection командою `mstsc`.
9. Ввести публічну адресу інстансу.
10. Використати ім’я `Administrator` та розшифрований пароль.
11. Підтвердити підключення та перевірити сертифікат.
