## 4. Короткі теоретичні відомості

Amazon Simple Storage Service, або Amazon S3, — це хмарний сервіс об’єктного зберігання даних. Він дозволяє зберігати документи, зображення, відео, резервні копії, програмні файли та статичні вебсторінки.

Дані в Amazon S3 організовано у вигляді бакетів та об’єктів. Бакет є логічним контейнером для файлів, а кожен завантажений файл зберігається як окремий об’єкт.

Основні можливості Amazon S3:

* зберігання різних типів файлів;
* масштабованість;
* керування доступом;
* автоматичне шифрування об’єктів;
* підтримка версійності;
* реплікація даних;
* розміщення статичних вебсайтів;
* інтеграція з іншими сервісами AWS.

Статичний сайт складається з HTML, CSS, JavaScript, зображень та інших файлів, які не потребують виконання серверного коду.

Обраний регіон:

```bash

aws s3api create-bucket \
  --bucket "$APZ_BUCKET" \

  --create-bucket-configuration LocationConstraint="$APZ_REGION"
```

Після створення було виконано перевірку наявності бакета:


### 5.4. Завантаження сторінки до бакета

Файл `index.html` було завантажено до створеного бакета командою:

```bash
aws s3 cp index.html \
  "s3://titov-mykhailo-122-23-2-apz/index.html" \
  --content-type "text/html; charset=utf-8" \
  --cache-control "no-cache"
```

Параметр `content-type` вказує браузеру, що завантажений об’єкт є HTML-документом із кодуванням UTF-8.

---

### 5.5. Налаштування статичного хостингу

Для бакета було створено конфігурацію статичного вебсайту:

```json
{
  "IndexDocument": {
    "Suffix": "index.html"
  }
}
```

Конфігурацію застосовано командою:

```bash
aws s3api put-bucket-website \
  --bucket "$APZ_BUCKET" \
  --website-configuration file://website.json
```

Файл `index.html` визначено головною сторінкою сайту.

### 5.6. Налаштування публічного доступу

Оскільки сторінка повинна бути доступною через Інтернет, для бакета було змінено параметри Block Public Access:

```bash
aws s3api put-public-access-block \
  --bucket "$APZ_BUCKET" \
  --public-access-block-configuration \
  "BlockPublicAcls=false,IgnorePublicAcls=false,BlockPublicPolicy=false,RestrictPublicBuckets=false"
```

Для загальнодоступного читання об’єктів було створено політику бакета:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadWebsite",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::titov-mykhailo-122-23-2-apz/*"
    }
  ]
}
```

Політику застосовано командою:

```bash
aws s3api put-bucket-policy \
  --bucket "$APZ_BUCKET" \
  --policy file://bucket-policy.json
```

Політика дозволяє користувачам Інтернету лише читати об’єкти бакета. Вона не надає права змінювати або видаляти файли.

## 7. Відповіді на контрольні питання

### 1. Для чого найчастіше використовують AWS S3?

Amazon S3 найчастіше використовують для зберігання файлів, резервних копій, документів, зображень, відео, журналів, архівів, наборів даних та ресурсів вебзастосунків. Також S3 можна використовувати для розміщення статичних вебсайтів.

### 2. Які головні переваги використання AWS S3?

Головними перевагами Amazon S3 є:

* висока надійність зберігання даних;
* практично необмежене масштабування;
* доступ до об’єктів через Інтернет;
* оплата лише за фактичне використання;
* керування доступом за допомогою політик;
* автоматичне шифрування;
* підтримка версійності та реплікації;
* інтеграція з іншими сервісами AWS;
* можливість розміщення статичних сайтів.

### 3. Що таке Buckets (кошики)?

Bucket — це логічний контейнер Amazon S3, у якому зберігаються об’єкти. Кожен бакет має унікальне ім’я, визначений регіон і власні налаштування доступу, версійності, шифрування та статичного хостингу.

### 4. Що містить об’єкт у сервісі AWS S3?

Об’єкт Amazon S3 містить:

* дані файлу;
* унікальний ключ, який виконує роль імені;
* метадані;
* інформацію про тип вмісту;
* ідентифікатор версії, якщо ввімкнено версійність;
* параметри доступу;
* контрольну суму та іншу службову інформацію.

### 5. Як створити власний кошик у сервісі AWS S3?

Для створення бакета потрібно:

1. Увійти до AWS Management Console.
2. Відкрити Amazon S3.
3. Натиснути `Create bucket`.
4. Увести глобально унікальну назву.
5. Вибрати регіон.
6. Налаштувати параметри доступу, шифрування та версійності.
7. Натиснути `Create bucket`.

Також бакет можна створити через AWS CLI:

```bash
aws s3api create-bucket \
  --bucket назва-бакета \
  --region eu-central-1 \
  --create-bucket-configuration LocationConstraint=eu-central-1
```
